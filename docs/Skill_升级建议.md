# Skill 升级建议

以下是建议新增（按优先级）：

1. `security-threat-model`
- 用途：飞书回调、远程指令、密钥使用链路做威胁建模。

2. `security-best-practices`
- 用途：配置分层、日志脱敏、密钥轮换规范化。

3. `sentry`
- 用途：后端异常聚合、前端报错采集、告警收敛。

4. `gh-fix-ci`
- 用途：后续接入 CI 后自动定位与修复常见流水线失败。

可选：

5. `vercel-deploy`
- 场景：未来如恢复独立前端发布到 Vercel。

6. `openai-docs`
- 场景：后续引入 AI 选题分析时快速对齐官方实践。

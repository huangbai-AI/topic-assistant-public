# 运行故障手册（1页）

## 常见错误码与处理

### 1) 云端访问 `530`（常见）
- 含义：Cloudflare 隧道未注册完成或隧道进程未运行。
- 处理：
  1. `cd $HOME/选题插件开发 && ./scripts/topic_cloud.sh status`
  2. 若 tunnel 未运行：`./scripts/topic_cloud.sh start`
  3. 再测：`curl https://your-topic-assistant.example.com/api/health`
  4. 若使用开机托管，再看：`./scripts/launchd_manage.sh status`

### 2) 云端访问 `502`
- 含义：隧道在线，但后端源站不可达（端口未监听/进程退出）。
- 处理：
  1. `./scripts/topic_cloud.sh status`
  2. 若 backend 未运行：`./scripts/topic_cloud.sh restart`
  3. 查看日志：`tail -n 120 /tmp/topic_backend.log`

### 3) 接口 `401`
- 含义：API Key 错误，或附件 token 过期。
- 处理：
  1. 控制台“配置”页确认 API Key
  2. 风控附件链接过期时，重新从风控列表或飞书最新消息打开

## 一键恢复命令

```bash
cd $HOME/选题插件开发
./scripts/topic_cloud.sh restart
```

## 常用排障命令

```bash
# 查看服务状态
./scripts/topic_cloud.sh status

# 后端日志
tail -n 120 /tmp/topic_backend.log

# 隧道日志
tail -n 120 /tmp/topic_tunnel.log

# 本地健康
curl http://127.0.0.1:8000/api/health

# 公网健康
curl https://your-topic-assistant.example.com/api/health
```

## 开机自启（可选）

```bash
cd $HOME/选题插件开发
./scripts/launchd_manage.sh install
./scripts/launchd_manage.sh status
```

说明：`install` 会托管 `backend + tunnel + frontend`。  
如需纯手动模式：

```bash
./scripts/launchd_manage.sh uninstall
```

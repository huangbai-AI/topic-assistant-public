# 两周实施看板（稳定性优先）

## Week 1（P0：稳定性收敛）

1. 前端入口收敛（已完成）
- 目标：消除双实现分叉。
- 验收：前端统一跳转 `/dashboard`。

2. 任务执行模型统一（已完成）
- 目标：手动/飞书/定时共用一套队列。
- 验收：统一入队；单 worker 串行执行。

3. 覆盖参数隔离（已完成）
- 目标：任务级参数不污染全局配置。
- 验收：`scrape_headless` 改为任务上下文。

4. 回调安全加固（已完成）
- 目标：阻止伪造与重放请求。
- 验收：签名+时间窗+nonce 防护生效。

5. 错误协议统一（已完成）
- 目标：接口可诊断性提升。
- 验收：结构化错误 + request_id。

## Week 2（P1：体验与运维）

1. 弹窗状态模块化（已完成）
- 手动触发弹窗引入独立状态对象（`triggerModalState`），降低勾选状态漂移。
- 增加“恢复最近选择”与本地记忆（模式 + 关键词范围）。

2. 任务中心可视化增强（已完成）
- 增加状态过滤、数量过滤。
- 增加耗时、失败原因列，便于快速排障。

3. 登录失效恢复链路（部分完成）
- 风控事件列表新增恢复建议、截图/HTML 快照直达链接。
- 新增 `GET /api/risk/events/{event_id}/artifact`（支持 API Key 鉴权）。
- 飞书告警模板增强待后续一并收敛。

4. 运维守护闭环（待办）
- systemd/supervisor 托管后端与 cloudflared。
- 健康探针 + 自动重连 + 日志切割。

## 风险登记

1. 本地单机运行时，机器休眠会导致任务中断。
2. 小红书风控策略变化会影响抓取稳定性。
3. 飞书权限与事件订阅变更可能影响回调可用性。
